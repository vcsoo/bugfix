# 검수 기록 — YYYY-MM-DD

- **대상**: <저장소·범위>  · **커밋**: `<sha>`
- **돈 축**: 1~20 (건너뜀: 19 — 이유)
- **결과**: 치명 0 · 높음 2 · 중간 5 · 낮음 3 · 잠재 1
- **실데이터**: 읽기만 함 (쓰기·삭제·발송 없음)

## 요약 — 먼저 결정해 주실 것

1. **[H1]** … (한 줄) → 제안: …
2. **[H2]** … → 제안: …

## 항목

### [C1] 한 줄 제목 — 축: 5 불변식 / 구역: 휴가
- **도달 경로**: 어떤 사람이 어떤 화면·API 에서 무엇을 하면 닿는가
- **재현**: 시험 파일·번호 (재현 못 하면 «잠재» 로 등급을 내린다)
- **피해**: 무엇이 틀어지나 · 되돌릴 수 있나 · 알아챌 수 있나
- **제안**: 어디를 어떻게 (한 곳에서 막는 방법 우선)
- **상태**: 고침 / 정책 / 보류 / 사람이 실행
